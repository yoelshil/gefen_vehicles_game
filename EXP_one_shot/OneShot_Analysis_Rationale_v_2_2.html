1. Executive Summary

Complete statistical pipeline for the OneShot distributional learning experiment. Participants estimate a probability distribution [1, 1, 4, 6] across 4 items (N=12 total) from two brief exposures, across four phases: Blind Prior, Icon Prior, Trial 1 (exposure + SAD feedback), Trial 2 (exposure + SAD feedback).

Primary DV: SAD (Sum of Absolute Deviations from true distribution), range 0-22, always even for N=12.

Pipeline principles: (1) plan before execute, (2) figure-driven analysis grouping, (3) non-parametric statistics throughout, (4) versioned outputs, (5) no external dependencies beyond standard scientific Python.

Order-statistic artifact and the rare-mean companions (v_2_2):

Two items in the true distribution have count = 1 (both "rare"). In panels 2.4, 2.5, 3.3, 4.1, 4.2 and 4.7 these two estimates are split into rare_min = min(esta, estb) and rare_max = max(esta, estb). Sorting two values into a min slot and a max slot is an order statistic: for any two draws from the same distribution, E[max] ≥ E[mean] ≥ E[min] by construction. So even when a participant has no role knowledge and guesses near-uniformly, the rare_max bar is pulled up and rare_min is pulled down.

Why this misleads. In the Icon phase (no data seen yet) participants tend to spread estimates ~uniformly. Suppose a participant types [rare_a=2, rare_b=4, medium=3, dominant=2]. The split gives rare_min=2, rare_max=4, medium=3, dominant=2 — making rare_max (4) look higher than both medium and dominant, purely from noise, not from believing the rare items are common.

Shape classification tie-breaking (v12): 3-tier: SAD -> chi-square -> Mixed composite. All ties logged.
Why [2,3,3,4] classifies as Uniform, not Unimodal (v23):

The classification is a nearest-neighbor assignment: compute SAD between the sorted response and each of 5 sorted reference distributions, pick the minimum. For [2, 3, 3, 4]:
ReferenceSorted shapeSAD computationSAD
Uniform[3, 3, 3, 3]|2-3| + |3-3| + |3-3| + |4-3|2 ← winner
Unimodal-mild[1, 2, 3, 6]|2-1| + |3-2| + |3-3| + |4-6|4
J-shaped (True)[1, 1, 4, 6]|2-1| + |3-1| + |3-4| + |4-6|6
Bimodal-symmetric[1, 1, 5, 5]|2-1| + |3-1| + |3-5| + |4-5|6
Unimodal-extreme[0, 1, 2, 9]|2-0| + |3-1| + |3-2| + |4-9|10

Why this is defensible: [2, 3, 3, 4] has a range of only 2 (max minus min). The "peak" at 4 is just 1 unit above the mean of 3. Compared to the Unimodal-mild reference [1, 2, 3, 6] (range = 5, clear dominant value), [2, 3, 3, 4] reflects approximately equal allocation with minor noise, not item differentiation.

What it means for interpretation: "63% Uniform" includes participants who produced [2, 3, 3, 4] (most common, P=19.8% under null), [2, 2, 4, 4], and exact [3, 3, 3, 3]. The label "Uniform" therefore means "no meaningful differentiation between items" rather than "exactly equal counts." This is a category label capturing a behavioral pattern (flat allocation), not a literal descriptor. For the stricter question ("how many produced exactly [3, 3, 3, 3]?"), Panel 9.2 provides exact distribution counts per phase, bypassing the classification entirely.

Design choice: The classification is a nearest-neighbor classifier with 5 fixed prototypes representing qualitatively distinct distributional shapes. Its granularity depends on the reference set. Adding a 6th reference (e.g., "near-uniform" = [2, 3, 3, 4]) would split the current Uniform category but might not add interpretive value, since the core question is whether participants differentiate between items at all.
Classification significance tests (v19): Tests whether observed classification proportions differ from what Multinomial(12, uniform) noise would produce. Method: simulate 100,000 experiments (N participants each), classify each simulated participant using the same 5-reference + tiebreaker system, record null classification proportions.

Tests performed:
(1) Per-category test: For each of 5 categories, two-tailed simulation test comparing observed count to null count distribution. Answers: "Is 63% Uniform surprising under H0?"
(2) Binary test: Uniform vs Non-uniform. Compares observed Uniform count to null Uniform count.
(3) Top-2 test: Uniform + Unimodal-mild combined. Tests if these two categories together capture more participants than expected.
(4) Model comparison: Stepwise from k=5 to k=2 categories. At each k, merge least frequent categories into "Other" and compute chi-square GoF (observed vs null expected). Simulation p-value. Shows which k first becomes significant.

Note: with small N, some categories may have 0 observed participants. The simulation-based p-values handle this naturally (no minimum expected count assumption unlike parametric chi-square).
How classification proportion p-values are computed (v22):

Per-category (e.g., Uniform):
1. In each of 100,000 simulated experiments (N participants from Multinomial(12, uniform)), classify all simulated participants using the same 5-reference SAD system.
2. Count how many are classified as "Uniform" in each simulation. Average across simulations = null expected proportion (e.g., 29.5%).
3. Compute observed deviation: |observed_count - null_mean_count| (e.g., |19 - 8.9| = 10.1).
4. For each simulation, compute its deviation from null mean: |sim_count - null_mean_count|.
5. p = proportion of simulations with deviation >= observed deviation (two-tailed).

Combined categories (e.g., Uniform + Unimodal-mild):
Same procedure but summing counts for the combined categories before computing deviations.

Interpretation note: Even under the null, the 5 categories are NOT equally likely. Multinomial noise naturally produces responses that classify as Uniform (~30%) or Unimodal-mild (~60%), because random responses close to [3,3,3,3] have smallest SAD to the Uniform reference, and slightly skewed responses like [1,3,3,5] classify as Unimodal-mild. Responses classifying as Bimodal or J-shaped are rare under noise. The null expected proportions account for this.

Consequence: the combined Uniform + Unimodal-mild proportion may NOT be significant (null already expects ~91% in these two categories), even when the individual Uniform proportion IS significant (observed 63% vs null 29.5%). The excess Uniform participants come at the expense of other categories, not Unimodal-mild.
Item-level phase tests (v12): (A) Per-item Wilcoxon Blind vs Icon (Bonf. 0.0125). (B) Per-item Friedman across 4 phases. (C) Interaction Friedman on shift magnitudes.
Prior test correction (v15): Old sign-flip test compared mean SAD to 0 (always rejects). Corrected simulation test uses Multinomial(12, uniform) null. Now two-tailed: tests whether observed mean SAD is DIFFERENT from null expectation (~4.65) in either direction. p = proportion of simulated |deviation from null mean| >= observed |deviation|. Three outcomes: (1) p<.05, observed > null: reject H0, observed was higher than expected. (2) p<.05, observed < null: reject H0, observed was lower than expected. (3) p>.05: fail to reject H0, data consistent with multinomial noise. The direction is a descriptive observation; the p-value only indicates whether the data is inconsistent with the multinomial model.
Null distribution discreteness (v15): SAD from [3,3,3,3] is always even because deviations sum to zero (SAD = 2 * sum of positive deviations). The mean of N even integers has granularity 2/N. With N=30, possible mean values are spaced 0.0667 apart. A naive histogram with bin width close to this spacing creates artificial spikes. Panel 2.6 uses dual visualization: (1) histogram with many bins (shows discrete structure) and (2) KDE with bandwidth=0.15 (provides smooth envelope for interpretation).

How to interpret the classification proportion test and Panel 9.4 (v23):

This walkthrough explains the logic behind the P4 statistic ("Is the observed Uniform proportion surprising?") in four layers, from participant-level to figure-level.

Layer 1: Classification (per participant). Each participant's blind-phase response is a vector of 4 counts summing to 12, e.g., [2, 4, 3, 3]. Since blind-phase stimuli are gray squares with no item identity, position is meaningless. The vector is sorted ascending: [2, 3, 3, 4]. This sorted vector is compared via SAD to 5 sorted reference distributions (Uniform [3,3,3,3], Unimodal-mild [1,2,3,6], Unimodal-extreme [0,1,2,9], Bimodal-symmetric [1,1,5,5], J-shaped [1,1,4,6]). The participant is classified as the reference with the minimum SAD. Ties are broken by chi-square distance. Result for N=30: 19 participants (63%) classified as Uniform.

Layer 2: The 34-distribution space (what responses are possible). There are exactly 34 distinct sorted ways to distribute 12 counts across 4 bins (a ≤ b ≤ c ≤ d, a+b+c+d=12). Each has a known multinomial probability under uniform sampling [.25, .25, .25, .25]. Of these 34 distributions, only 3 classify as Uniform via the SAD system (those closest to [3,3,3,3]). Unweighted: 3/34 = 8.8%. But [3,3,3,3] and near-uniform distributions have high multinomial probability (many permutations), so when weighted by probability, ~29.5% of random draws would classify as Uniform. This 29.5% is the null expectation.

Layer 3: Monte Carlo simulation (the test). The question: "Is 63% Uniform surprising given that chance already predicts 29.5%?" There is no closed-form formula for the null distribution of "proportion classified as Uniform in a sample of N" because the classification pipeline (sort, compute SAD, apply tiebreaker) is non-linear. So we simulate: (1) draw N=30 random Multinomial(12, [.25,.25,.25,.25]) vectors, (2) sort each, (3) classify each using the same 5-reference system, (4) record the proportion classified as Uniform. Repeat 100,000 times. The p-value (two-tailed) is the proportion of simulations where |sim_proportion - null_mean| ≥ |observed_proportion - null_mean|. With 63% observed vs 29.5% null, fewer than 0.1% of simulations reach that deviation. Hence p < .001.

Layer 4: Reading Panel 9.4. Panel 9.4 shows paired bars for each of the 5 classification categories. The lighter bar (with SD error bars from the simulation) represents the null expected proportion. The solid colored bar represents the observed proportion from the data. Significance stars above indicate the two-tailed Monte Carlo p-value. For the Uniform category: a short null bar (~29.5%) next to a tall observed bar (~63%) with *** stars. The visual gap between those two bars is the effect. Other categories (e.g., Unimodal-mild) may show smaller or non-significant gaps because the null already expects high proportions for those categories.

Monte Carlo Simulation and Exact Tests in This Pipeline v22

This pipeline uses two approaches to test null hypotheses about participant responses: Monte Carlo simulation (when analytical solutions don't exist) and exact computation (when they do). Understanding when each is used clarifies the statistical logic.

The 34-Distribution Space

There are exactly 34 distinct sorted distributions of 12 counts across 4 items. This is the complete universe of possible participant responses (when sorted ascending to remove position identity). Enumeration: a ≤ b ≤ c ≤ d, a+b+c+d=12. Breakdown: a=0 (19 distributions), a=1 (10), a=2 (4), a=3 (1, only [3,3,3,3]).

Each of these 34 has an exact multinomial probability under any model. For example, under uniform [.25,.25,.25,.25], [3,3,3,3] has P = 12!/(3!)^4 × (1/4)^12 = 0.022 (2.2%). This is computed analytically using the multinomial probability formula, not by simulation.

When Monte Carlo Simulation Is Needed

Monte Carlo is needed when the question involves a derived statistic whose null distribution has no closed form. The classification system (sort, compute SAD to 5 references, apply chi-square tiebreaker, count proportions) is such a case. There is no formula for "what proportion of multinomial draws classify as Uniform." The only way to find out is to generate many draws and count.

The chain of logic (same for all Monte Carlo tests):

  1. Define H0: participants draw from Multinomial(12, [.25, .25, .25, .25])
  2. Define the question: e.g., "what proportion get classified as Uniform?"
  3. Simulate: generate 100,000 fake experiments under H0. Each = N simulated participants, each drawing from multinomial, sorted, classified using the same system
  4. For each fake experiment: compute the answer to the question (e.g., "47% were Uniform")
  5. Compare: place the real observed answer against the 100,000 fake answers
  6. p-value: proportion of fake experiments at least as extreme as the real observation (two-tailed: deviation in either direction)

Concrete example (classification proportion test):

One simulation run (one "fake experiment"):
  Fake participant 1: Multinomial(12,[.25,.25,.25,.25]) -> [4,2,3,3]
    Sort: [2,3,3,4] -> SAD to Uniform=2, SAD to Unimodal=6, ... -> "Uniform"
  Fake participant 2: Multinomial -> [1,5,3,3]
    Sort: [1,3,3,5] -> SAD to Uniform=4, SAD to Unimodal=2, ... -> "Unimodal-mild"
  ... repeat for all N participants
  Result: 14/30 = 47% classified as Uniform

After 100,000 runs: null distribution of "% Uniform" values.
Observed = 63%. p = proportion of simulations with deviation >= observed deviation.

Why Multinomial is the correct null: It models exactly what "no knowledge" means. A participant with no distributional knowledge has no reason to favor any item. Each of their 12 counts goes to each of 4 items with probability 1/4. The multinomial enforces the sum-to-12 constraint, unlike independent draws from 0-12. Under this null, only 2.2% of draws produce exactly [3,3,3,3], and the expected mean SAD from uniform is ~4.65 (not 0).

13. Methodological Notes

Prior uniform test correction (v15)

The original sign-flipping permutation test (v1-v14) tested H0: "mean SAD from uniform = 0." This is wrong because SAD is always >= 0, and even a truly uniform Multinomial(12, [.25,.25,.25,.25]) prior produces mean SAD ~4.65 due to sampling noise. Only ~2% of multinomial draws give exactly [3,3,3,3].

The corrected test (v15) simulates 10,000 datasets of N participants drawing from Multinomial(12, [.25,.25,.25,.25]), computes mean SAD for each, and asks: "Is the observed mean SAD significantly HIGHER than this null?" If p > 0.05, participants are no more non-uniform than multinomial noise predicts. If the observed mean SAD is LOWER than the null expectation, participants are actively choosing uniform allocations.

The old sign-flip test is retained in the report as "[Deprecated]" for comparison.

Shape classification tie-breaking (v12)

3-tier system: (1) Primary: minimum SAD to 5 sorted references. (2) If SAD tied: chi-square distance Sum((O-E)^2/max(E,0.5)) as secondary tiebreaker. (3) If still tied: composite "Mixed" category (e.g., "Uniform + Bimodal-symmetric"). All ties are logged with: response vector, tied references, SAD value, resolution method, winner, chi-square scores. Tie rate is reported in the text output. With N=29, empirically ~3-5 participants have SAD ties; most are resolved by chi-square.

Why mean rather than median for prior comparison (Figure 2.5)

(1) Means preserve the sum-to-12 constraint across items. (2) With integer estimates, medians collapse to the same whole number across conditions, hiding real differences. (3) SAD is a mean-based distance metric. Both are shown (bars = mean, red dashes = median); divergence signals skewness.

Item identity across trials

Item numbers (1-4) are shape identities, not screen positions. gen_est_item4 always records the estimate for the dominant shape (true=6) regardless of screen position. In the blind phase, shapes are replaced by gray squares, so item-specific comparisons are chance-level baselines. Shape classification handles this by sorting.

Boxplot collapse on discrete data

When many participants give the same integer estimate, Q1=median=Q3 and the box has zero height. This indicates consensus, not a plotting error. Common for rare items (most participants assign ~3).

Regression to the mean in feedback analysis

The T1 SAD vs improvement correlation (7.8) is confounded by RTM: extreme T1 values regress toward the mean on T2 regardless of learning. The T1 vs T2 correlation (7.7) is cleaner. Both reported with explicit caveat.

SAD is always even for N=12

When 4 estimates sum to 12 and the true distribution also sums to 12, the SAD = Sum|est_i - true_i| is always even. This constrains the distribution of SAD values and means feedback bands should use even intervals.

The Problem

The experiment CSV columns gen_est_item1 through gen_est_item4 are positional: they record the estimate for screen position 1 (leftmost) through 4 (rightmost). Screen positions are shuffled randomly each non-blind trial via shuffleRandom(), so gen_est_item1 in Trial 1 and Trial 2 can correspond to different items. All v1.x analyses (v7-v30) incorrectly treated these as item-specific, corrupting all item-level results.

The Fix: Role-Based Remapping

For each non-blind trial, the pipeline now:

  1. Reads gen_pos{i}_item to determine which item was at each screen position
  2. Reads count_mapping (e.g., "17:1 18:6 19:1 20:4") to determine each item's true count
  3. Maps each positional estimate to its role: role_est_dominant (true=6), role_est_medium (true=4), role_est_rare_min/max (true=1)

Two items share true_count=1. These are tracked as rare_min (lower estimate), rare_max (higher estimate), rare_mean, and rare_spread (|max - min|).

rare_min/rare_max is an order statistic (see v_2_2): Because rare_min/rare_max are the min/max of two estimates, they are systematically deflated/inflated (E[max] ≥ E[mean] ≥ E[min]) even under pure noise. v_2_2 therefore adds rare-mean companion panels (2.4m, 2.5m, 3.3m, 4.1m, 4.2m, 4.7m) that plot rare_mean as a single slot. Blind Phase: Shape Alignment (Not Item Knowledge)

Critical distinction: The blind phase uses abstract labels (W, X, Y, Z), not real items. There is no item identity to recover. The sorted blind comparison ranks the participant's four estimates in ascending order and aligns them to the sorted true distribution [1, 1, 4, 6]. This measures distributional shape similarity — whether the participant's response has the right rank structure (two low, one medium, one high) — not item-level knowledge.

A participant who gives [2, 3, 3, 4] has a distribution shape close to [1, 1, 4, 6]. Whether they assigned "2" to position W or Z is irrelevant for the shape question. The smallest estimate aligns to the smallest true count by rank, not by identity.
